# Changelog

All notable changes to this project will be documented in this file.

## [1.5.0] - 2026-06-01

### Added
- New project templates for Next.js, React, Vue, Svelte, and Angular.
- Backend templates for Rust, Python, and .NET.
- Interactive terminal menu with improved navigation.
- System dependency checking.
- Automated release workflow with `cargo-dist`.

### Fixed
- Improved project initialization speed.
- Fixed folder naming issues on Windows.
- Better error handling for missing dependencies.
